PROJECT OVERVIEW

About AI POWERED FAKE NEWS DETECTOR

An academic prototype exploring machine learning for news analysis.

Problem statement

Online information spreads rapidly. This project classifies text patterns and provides tools to inspect explanations, related references, and similar stories.

Objectives

  • Train and evaluate a text classifier.
  • Expose predictions through a multi-page Flask application.
  • Store analyses and feedback in SQLite.
  • Provide explainability and source discovery.
  • Encourage responsible verification.

Technology stack

Python, Flask, pandas, scikit-learn, TF-IDF, SQLite, HTML, CSS, JavaScript, ReportLab.

Limitations

Dataset bias, language differences, and translation affect performance. Search results are not a verdict. This is a decision-support prototype, not an authoritative fact checker.
